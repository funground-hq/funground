# Creative practice with funground: the sketches

These are original CC0 examples; see [the examples licence](../LICENSE).
They support the course [Creative practice with funground](../../docs/course/README.md).

Download a Python file and run it in the environment where Funground is installed.
For example, run **python 01_starter.py**. It saves a PNG in your current folder,
then displays the drawing. Close the window to finish.

The starter and exercise sketches use short scripts. The comparison sketches use loops to
arrange several studies on one sheet. The core sketches use the base install. The optional GIF exporter needs funground[extras] or ffmpeg.
Lesson 9's live sketches run continuously; close their window to finish.
