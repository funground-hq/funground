# A funground book: Chapter 1

A test chapter of a book for learning to draw with code, laid out and drawn entirely by funground. It is work in progress (story S-225): the page size and the details may change.

Each spread is two facing pages. The pictures are made by running the sketches the pages show, so the code and its picture always agree.
