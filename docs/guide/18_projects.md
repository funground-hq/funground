# 18. Projects

You have learned the pieces. Now put them together. A project is a bigger piece of work that uses
many things at once. Each one has its own page, and each comes in three stages.

1. **Make it work.** A small version. It does one thing, and it runs.
2. **Make it yours.** Change it. Add the things you care about.
3. **Make it shine.** The full version in the examples gallery. Read it, run it, and borrow from it.

At the end of each project there are **challenge cards**. Each card is one short job to try on your own.
There is no right answer. If it looks good to you, it is done.

## How to use a project page

1. Read the intro and **How it works**. It shows the core idea, with short pieces from the real example.
2. Copy the Stage 1 code into a file and run it. Every complete example on a project page runs
   as printed. A short piece marked as a fragment is not a whole program. It goes into your own sketch.
3. Pick the Stage 2 ideas you like, one at a time. Run it after each one.
4. Run the full example from the gallery, then read its code. The top of the file explains how it works.
5. Try a challenge card. Pick any one.

You do not have to do the projects in order. Pick the one that sounds like fun.
