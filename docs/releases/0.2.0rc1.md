# funground 0.2.0rc1: the release candidate for 0.2

A **release candidate** of funground 0.2: everything described in the
[changelog](https://github.com/funground-hq/funground/blob/v0.2.0rc1/CHANGELOG.md) is in it and has its tests, and
it is what 0.2.0 will be unless the test pass below finds a problem. Please try it and report what you find in the
[issues](https://github.com/funground-hq/funground/issues).

```
python -m pip install --pre funground
```

`--pre` is needed: without it, pip installs 0.1.0. Python 3.11 or newer. On Linux, install the Cairo library first
(`sudo apt install libcairo2-dev pkg-config python3-dev` on Debian or Ubuntu); on macOS, if the install fails while
building `pycairo`, run `brew install cairo pkg-config` first.

## What is new in 0.2

- **The camera** (`from funground import camera`) and **the models library** (`from funground import ml`): a body and
  a hand in your camera or a photo, the person's outline, the words you say, the name of a sound, and a model you
  teach yourself. Everything runs on your own computer; no picture or sound leaves it.
- **Projects with the models:** a stick figure from your own photo, six pose projects, and a cut-out puppet that copies
  you, records a dance, replays it on any drawing and prints it as a flip book.
- **Sound and the music of India are libraries** (`from funground import sound`, `sangeet`): a sketch from 0.1 that
  makes sound needs two small changes, and funground's message says which.
- **Editors suggest what to type**, in VS Code and in Play, and know what each model gives back.
- **A box for a laser cutter:** six panels with fingers that lock together, drawn at true size.
- Fonts from the web, layers that cost little, and fixes for the microphone, long recordings and sound files in Play.

## Known problems

- **funground-ml, the models library, is not on PyPI yet**: it is published with 0.2.0. To try the models with this
  release candidate, install it from GitHub:
  `python -m pip install "funground-ml @ git+https://github.com/funground-hq/funground@v0.2.0rc1#subdirectory=ml"`.
- **On phones**, in Play: the camera does not focus well, the toolbar takes several rows above the picture, the
  keyboard covers most of the editor, and painting with a finger does not work.

## Not yet tested

These work in the automatic tests, but nobody has yet tried them by hand:

- Play in **Safari on an iPhone**, and the camera and model examples on an Android phone after the last changes;
- the **finger-jointed box** (gallery project 10) cut on a real laser cutter;
- the **servo puppet** (guide project 12) on a real ESP32 with servos;
- a real **macOS** or **Linux** desktop with a camera.

Tried by hand during 0.2: the camera and model examples on Windows, and Play in Chrome on Windows and on one Android
phone.
