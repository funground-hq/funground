# funground 0.1.0

funground is a Python library for drawing, animation, typography, print and sound, made for learning.
0.1.0 is its first full release, after the alpha (0.1.0a1, 12 October 2026). Everything in the
[changelog](https://github.com/funground-hq/funground/blob/v0.1.0/CHANGELOG.md) is in it and has its tests.
Please report what you find in the [issues](https://github.com/funground-hq/funground/issues), or ask in
[Discussions](https://github.com/funground-hq/funground/discussions).

```
python -m pip install funground
```

Python 3.11 or newer. On Linux, install the Cairo library first
(`sudo apt install libcairo2-dev pkg-config python3-dev` on Debian or Ubuntu); on macOS, if the
install fails while building `pycairo`, run `brew install cairo pkg-config` first.

## What is in it

- Drawing, colour, transforms, paths, text and typography, animation, interaction, controls,
  pictures and pixels, noise and randomness.
- Pages in real units (`f.size("A3", margin=f.mm(15))`), grids and areas, multi-page documents, and
  print-ready output: PDF with bleed and crop marks, CMYK inks (`f.cmyk()`), PNG at a chosen dpi, SVG.
- Rich text: text boxes that flow, justify and hyphenate; text on a path; headlines fitted to a box.
- Sound: tunes, sargam, ragas and talas, listening and the microphone.
- Two ways to write a sketch: with `import funground as f`, or with `from funground import *` and
  no `f.` at all.
- The same sketches run in the browser on the [Play page](https://funground-hq.github.io/play/).
- A User Guide, a course (*Creative practice with funground*), an Examples Gallery
  (`python -m funground.gallery`), projects and studios, a Quick Reference and an API reference.
- Pages for AI assistants: `llms.txt` and `llms-full.txt`, in the repository and in the package.

## New since the alpha

- **The course** *Creative practice with funground*: eleven lessons, from composition and colour to
  type, posters, motion and generative work.
- **Pages for AI assistants** (`llms.txt`, `llms-full.txt`) and `AGENTS.md` for agents that change funground.
- **`f.run(fps=...)` works**: `f.size()` in `setup()` no longer resets the frame rate.
- **Library versions have upper bounds**, and the exact versions this release was tested with are
  attached to the GitHub Release as `tested-versions.txt`. A school or course that wants exactly those installs with
  `pip install funground -c https://github.com/funground-hq/funground/releases/download/v0.1.0/tested-versions.txt`.

## Not yet tested

These work in the automatic tests on Windows, macOS and Linux, but nobody has yet tried them by hand:

- a real **macOS** or **Linux** desktop: the gallery browser, a window on a high-resolution screen,
  full screen, keyboard and mouse, the controls panel, sound and the microphone;
- **SVG text in Illustrator and Inkscape**: whether saved Hindi and Latin text can be edited and is
  shaped correctly;
- the **raga data** (`funground/data/ragas.json`), not yet checked by a musician.

Tried by hand on Windows: the microphone, listening to the sound examples, and the Play page.

## Known problems

- In the browser, a JPEG picture decodes slightly differently from the desktop (colour edges; D-101).
- The first visit to the Play page downloads about 12 MB and takes 10 seconds or more on a slow connection.
