# funground 0.1.0a1: the first alpha

The first public release of funground, a Python library for drawing, animation, typography, print
and sound, made for learning. It is an **alpha**: everything described in the
[changelog](https://github.com/funground-hq/funground/blob/v0.1.0a1/CHANGELOG.md) is in it and has
its tests, but parts have not been tried on every system, and a few known problems are still open.
Please report what you find in the [issues](https://github.com/funground-hq/funground/issues).

```
python -m pip install funground
```

Python 3.11 or newer. On Linux, install the Cairo library first
(`sudo apt install libcairo2-dev pkg-config python3-dev` on Debian or Ubuntu); on macOS, if the
install fails while building `pycairo`, run `brew install cairo pkg-config` first.

## What is in it

- Drawing, colour, transforms, paths, text and typography, animation, interaction, controls,
  pictures and pixels, noise and randomness.
- Pages in real units (`f.size("A3", margin=f.mm(15))`), grids and areas, and print-ready output:
  PDF with bleed and crop marks, CMYK inks (`f.cmyk()`), PNG at a chosen dpi, SVG.
- Rich text: text boxes that flow, justify and hyphenate; text on a path; headlines fitted to a box.
- Sound: tunes, sargam, ragas and talas, listening and the microphone.
- Two ways to write a sketch: with `import funground as f`, or with `from funground import *` and
  no `f.` at all.
- The same sketches run in the browser on the [Play page](https://funground-hq.github.io/play/).
- A User Guide, an Examples Gallery (`python -m funground.gallery`), projects and studios, a Quick
  Reference and an API reference.

## Known problems

- **The automatic tests are not all green on GitHub.** On GitHub's computers (not on the
  maintainer's Windows machine, where all tests pass):
  - on Linux with Python 3.12 the test run stops responding during the guide's tests; the cause is
    not yet known;
  - on Windows, a few reference pictures of rotated drawings differ slightly from the expected ones;
  - a newer version of a PDF-reading tool used only by the tests (pypdfium2 5.14) reads a Hebrew
    test sentence back in reverse order.
- The documentation for AI assistants (`llms.txt`, `AGENTS.md`) is not in this release yet.

## Not yet tested

These work in the automatic tests, but nobody has yet tried them by hand:

- a real **macOS** or **Linux** desktop: the gallery browser, a window on a high-resolution screen,
  full screen, keyboard and mouse, the controls panel, sound and the microphone;
- **SVG text in Illustrator and Inkscape**: whether saved Hindi and Latin text can be edited and is
  shaped correctly;
- the **raga data** (`funground/data/ragas.json`), not yet checked by a musician.

Tried by hand on Windows: the microphone, listening to the sound examples, and the Play page.
