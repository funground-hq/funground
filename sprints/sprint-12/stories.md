# Sprint 12 — release 0.1, widened: text depth and examples in the package

**Dates:** planned 2 Oct 2026 (D-049). Building starts once the commits made while GitHub was
unreachable are pushed and CI is green on all 12 cells (Sprint 11 retro rule).

**Goal:**
- letters missing from a font come from a fallback font;
- learners get the examples and the gallery browser with `pip install funground`;
- text as points, text-box overflow and font information;

**Checkpoint:**
- existing goldens and snapshots are unchanged;
