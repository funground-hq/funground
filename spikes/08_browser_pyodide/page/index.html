Text caveat. Text ops are drawn with ctx.fillText and the bundled DejaVu Sans loaded as a FontFace, i.e. the browser shapes and rasterises the text. This is not the deterministic outline route the desktop renderer uses (fontTools outlines positioned by HarfBuzz, emitted as FillPath ops), so glyph advances, kerning and hinting may differ per browser. It is option 4 of the Browser Mode Note; the spike's purpose is to check the shape ops and the plumbing, not to pin browser text.

Serve from the repo root (e.g. python -m http.server 8765) and open /spikes/08_browser_pyodide/page/index.html?snapshot=05_text; the font and goldens are fetched with ../../../ relative URLs. &shot=1 shows only the canvas at (0, 0) for headless screenshots.
